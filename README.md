# E-Commerce Project | La Plateforme_

Ce projet est une application de boutique en ligne développée dans le cadre de la formation Développeur Web et Web Mobile (DWWM) à La Plateforme_. L'objectif est de démontrer une maîtrise des technologies front-end modernes et des principes de développement d'interfaces performantes.


---

## Fonctionnalités

- Catalogue de produits : Affichage dynamique des articles avec gestion des catégories.
- Panier d'achat : Gestion complète de l'ajout, de la modification et de la suppression d'articles.
- Interface responsive : Adaptation ergonomique sur tous les types d'écrans (mobile, tablette, desktop).
- Interactions enrichies : Utilisation de transitions fluides pour améliorer l'expérience utilisateur.
- Sécurité typée : Développement sous TypeScript pour une maintenance et une robustesse accrues.

## Stack Technique

- Framework : Next.js (App Router)
- Langage : TypeScript
- Style : Tailwind CSS
- Animation : Framer Motion

---

## Installation et Utilisation

1. Cloner le dépôt
   git clone https://github.com/votre-compte/houppermans-esteban-dossiers-pros-DWWM.git

2. Installer les dépendances
   npm install

3. Lancer l'application en mode développement
   npm run dev

L'application est accessible par défaut sur l'adresse : http://localhost:3000

---

## Structure du Projet

- /app : Gestion des routes et des pages de l'application.
- /components : Composants UI réutilisables et modulaires.
- /public : Ressources statiques (images).
- /lib : initialisation des api.
